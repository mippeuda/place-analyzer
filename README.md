# 네이버 플레이스 분석기 v2.2

## 새 기능: 키워드 + 플레이스명 두 칸으로 순위 조회

1. Vercel에 이 ZIP 프로젝트를 배포하고, 발급받은 API 키를 **서버 환경변수**에 저장합니다.
2. 웹사이트를 Safari 또는 Chrome에서 접속합니다. 앱의 **순위 조회** 화면을 엽니다(첫 화면입니다).
3. 최초 1회만 `API 연결 설정`에서 `APP_ACCESS_CODE` 값을 입력해 저장합니다.
4. 검색창에 **키워드** `화정네일`, **플레이스명** `미쁘다네일`을 입력하고 **순위 조회**를 누릅니다.
5. 조회된 실제 매장명과 순위, 검색량(권한 설정 시), 저장 수, 블로그 리뷰, 방문자 리뷰 등이 카드에 표시됩니다. 비슷한 상호가 조회된다면 **다른 지점 선택**에서 정확한 매장을 다시 선택합니다.

### Vercel 환경변수

| 환경변수 | 필수 여부 | 설명 |
| --- | --- | --- |
| `RANKFREE_API_KEY` | 필수 | [Rankfree](https://rankfree.kr/developers) API 키. **`rank`** 권한 필요 |
| `APP_ACCESS_CODE` | 필수 | 앱 관리자만 아는 임의의 접속 암호. 이 값을 사이트의 **API 연결 설정**에 입력 |
| `RANKFREE_KEYWORD_API_KEY` | 선택 | **`keyword`** 권한이 있는 API 키. 미설정 시 `RANKFREE_API_KEY`를 사용하며, 해당 키에 `keyword` 권한이 없다면 검색량은 '확인 불가'로 표시 |

Vercel 프로젝트 **Settings → Environment Variables**에서 입력한 후 **다시 배포**합니다. API 비밀키를 `index.html`에 넣지 마세요.

### 표시되는 지표

- **검색 순위:** Rankfree의 광고 제외, 서울 기준 실시간 관측값입니다. 네이버 공식 순위가 아니며 사용자 위치·환경별로 다를 수 있습니다. `300` 또는 `found:false`는 **상위 300위 내 미노출**로 표시합니다. 실패·차단 응답은 순위로 표시하지 않습니다.
- **월간 검색량:** Rankfree의 `/keyword` 호출값(`monthly_total`)을 사용합니다. `keyword` API 권한·집계값이 없으면 '확인 불가'입니다.
- **저장 수 / 블로그 리뷰 / 방문자 리뷰:** 순위 조회 API가 반환한 실제 공개 값으로 표시합니다. 별도 상세정보 API로 확인할 수 있을 때 리뷰 수와 주소를 보강합니다. **방문자 리뷰 전체가 영수증 리뷰 개수와 정확히 같다는 뜻은 아닙니다.**
- **톡톡·예약·N페이·쿠폰:** 외부 상세정보에서 명시적인 상태값을 받은 항목만 ✓/×로 표시합니다. 확인이 불가능한 항목은 `?`로 둡니다. 없는 것으로 추정해 ×를 표시하지 않습니다.
- **최근 조회:** 이 브라우저에만 조회했던 검색어 조합이 저장됩니다. 사용자가 누르면 다시 조회합니다. 예전 조회값을 오늘의 수치인 것처럼 표시하지 않습니다.

### 기존 기능 유지

순위 화면의 **기존 순위 기록·추적 기능 열기**를 누르면 v2.1의 수동 키워드·순위 기록, 자동 추적, 차트 기능이 그대로 있습니다. 개요/유입·예약/경쟁/관리 메뉴도 유지했습니다.

### 기술 및 보안 참고

- 이 버전은 순위·검색량을 창작하거나 임의로 추정하지 않습니다. API 권한/서버 배포가 없으면 실시간 조회는 실행되지 않습니다.
- 랭크프리 API의 `rank/check`, `rank/place`, `rank/candidates`, `keyword`가 서버 API 라우트에 연결돼 있습니다. API 접속 비밀키는 **서버에서만** 사용합니다.
- 공개 서비스에 배포할 경우 관리자 코드 유출 방지, 요청량 제한, 서버 사용료와 외부 API 사용량/과금, 회원별 접근권한 등 추가 보호가 필요합니다.
- 프로젝트 파일을 iOS **파일 미리보기**에서 열면 자바스크립트가 실행되지 않을 수 있습니다. 배포한 **HTTPS 주소**를 Safari에서 여세요.

## 포함 파일

- `index.html`: 모바일 검색·결과 카드 + 기존 분석 페이지
- `api/rank.js`: 서버 API 프록시와 인증
- `vercel.json`: Vercel 함수 설정
- `.env.example`: 필요한 환경변수 이름
