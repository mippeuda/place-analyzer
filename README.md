# 네이버 플레이스 분석기 v2.3 (무료·키 없이 동작)

## 무엇이 달라졌나

v2.2까지는 순위 조회에 유료·회원제 외부 API(Rankfree) 키가 필요했습니다. 이 버전은 **API 키 없이** 네이버 모바일 플레이스(`m.place.naver.com`)의 검색 결과를 서버에서 직접 읽어 순위를 계산합니다.

- 브라우저에서는 키를 다루지 않습니다. 서버(Vercel 함수)가 네이버를 조회하고 결과만 돌려줍니다.
- 필요한 환경변수는 **`APP_ACCESS_CODE` 하나**입니다.

## 사용 방법

1. Vercel에 이 프로젝트를 배포하고 환경변수 `APP_ACCESS_CODE`에 원하는 관리자 암호를 넣습니다.
2. 배포된 HTTPS 주소를 Safari/Chrome에서 엽니다. 첫 화면이 **순위 조회**입니다.
3. `API 연결 설정`에서 `APP_ACCESS_CODE` 값을 한 번 입력해 저장합니다.
4. **키워드**에 `화정네일`, **플레이스명**에 `미쁘다네일 일산화정점`(또는 플레이스 ID/URL)을 넣고 **순위 조회**를 누릅니다.

### Vercel 환경변수

| 환경변수 | 필수 여부 | 설명 |
| --- | --- | --- |
| `APP_ACCESS_CODE` | 필수 | 앱 관리자만 아는 임의의 접속 암호. 사이트의 **API 연결 설정**에 같은 값을 입력 |

## 조회 방식과 한계 (정확히 알아두실 것)

- **순위**: 네이버 모바일 플레이스 검색 결과(`place/list`)의 유기적 항목을 **광고 제외** 상태로 최대 100개까지 읽고, 매장이 몇 번째인지 계산합니다. 검색 기준 좌표는 **서울시청(126.9780, 37.5665)** 이고, 다음 항목은 제외합니다: 네이버 광고(adBusinesses).
- **상위 100위 밖**이면 순위를 `300`(권외)으로 돌려주고 화면에는 `상위 300위권 밖`으로 표시합니다. 네이버 공식 순위가 아니라 **조회 시점의 공개 검색 결과 순서**이며, 검색자 위치·기기·시점에 따라 달라질 수 있습니다.
- **월간 검색량**: 네이버 검색광고 API 키가 없으면 확인할 수 없어 **'확인 불가'** 로 표시합니다(값을 지어내지 않습니다).
- **자동 순위 추적(매일 등록·슬롯)**: 이 무료 직접 조회 모드에서는 지원하지 않습니다. 화면의 **지금 순위 조회**로 확인하고, 필요한 순위는 기존 수동 기록 기능에 남겨 주세요.
- **리뷰 수**: 방문자 리뷰·블로그/카페 리뷰 수는 네이버가 공개하는 값을 그대로 표시합니다. 방문자 리뷰 수가 영수증 리뷰만의 개수와 같다는 뜻은 아닙니다.
- 네이버가 일시적으로 요청을 막으면(403/429) 순위를 **0/차단**으로 돌려주고 화면에는 '조회 실패 또는 일시 차단'으로 표시합니다. 잠시 뒤 다시 시도해 주세요. 같은 키워드는 60초 동안 서버 메모리에 캐시해 호출을 줄입니다.
- 네이버 화면 구조가 바뀌면 파싱이 깨질 수 있습니다. 그때는 `api/rank.js`의 `apolloState`/`organicBusinesses` 부분을 새 구조에 맞춰 고쳐야 합니다.

## 포함 파일

- `index.html`: 모바일 검색·결과 카드 + 기존 분석 페이지
- `api/rank.js`: 네이버 직접 조회 + 관리자 코드 검증 (외부 API 키 불필요)
- `vercel.json`: Vercel 함수 설정(최대 실행 60초)
- `.env.example`: 필요한 환경변수 이름
